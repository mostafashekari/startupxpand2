# Developer continuity — v4.2.0

The private handoff package is the continuity bundle for the current approved application. It contains:

- signed v4.2.0 APK and signature sidecar
- complete v4.2.0 source snapshot
- multilingual article add-on source
- original source backup supplied for the project
- private release-signing bundle
- build and pagination generation scripts
- validation reports and visual test captures
- GitHub Actions workflow template and secret-name template

Expected package:

`Startup-Xpand-v4.2.0-Private-Developer-Handoff.zip`

SHA-256:

`3a9f0b4d6efcd79e100a386757d7483e0bb5f0a210a20af5a98cb0cc773aef39`

Store at least two encrypted offline copies in separate locations. Treat the package as highly sensitive because it contains the Android release-signing material and signing configuration. Do not upload it to this public repository or a public cloud share.

A live GitHub token is intentionally not included. Tokens are revocable account credentials and should be created per developer with minimum permissions and an expiration date.
