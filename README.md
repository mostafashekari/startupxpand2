# Startup Xpand Android

آخرین نسخه تأییدشده پروژه **4.2.0** با `versionCode 40200` است.

## وضعیت نسخه 4.2.0

- رابط انگلیسی، ترکی و عربی با پشتیبانی کامل RTL برای عربی
- 399 مقاله برای هر زبان و 1,197 صفحه مقاله آفلاین در مجموع
- صفحه‌بندی استاندارد 20 مقاله‌ای؛ 20 صفحه برای هر زبان
- جست‌وجو، دسته‌بندی، ذخیره مقاله و ادامه مطالعه
- رابط تطبیقی برای گوشی و نمایشگرهای عریض
- لوگوی هماهنگ در برنامه، Splash، Adaptive Icon، Round Icon و Themed Icon
- Target SDK 36 و حداقل Android 7
- رابط Next.js/TypeScript در پوسته Android مبتنی بر Capacitor و Kotlin

## فایل‌های مرجع انتشار

مشخصات، هش‌ها و روش بازیابی نسخه در `RELEASE-v4.2.0.md` ثبت شده است. بسته خصوصی تداوم توسعه شامل سورس کامل، APK امضاشده، بکاپ اصلی، کلید انتشار و مقادیر آماده GitHub Actions Secrets است و باید خارج از ریپازیتوری عمومی نگهداری شود.

## امنیت

کلید خصوصی امضا، گذرواژه‌ها، فایل Secrets و توکن GitHub عمداً در این ریپازیتوری عمومی قرار نمی‌گیرند. توکن زنده باید فقط با دسترسی حداقلی ساخته و در Password Manager یا GitHub Actions Secrets نگهداری شود.

فرایند قدیمی ساخت 4.1.5 غیرفعال شده است تا Artifact اشتباه به‌عنوان آخرین نسخه تولید نشود.
